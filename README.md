# Bé Chơi Chạm

Game chạm cho bé 18 tháng: **Con vật kêu gì?** (37 con vật, giọng nữ đọc tên) và **Chạm đâu nở đó**.

Chơi tại: https://tranthevinh-cdth17pmc.github.io/be-choi/

Bấm nút ⌂ ở góc trên bên trái để về màn hình chính.

Giọng đọc tạo bằng [Piper](https://github.com/rhasspy/piper) với giọng `vi_VN-vais1000-medium` (dữ liệu VAIS-1000, CC BY 4.0).
